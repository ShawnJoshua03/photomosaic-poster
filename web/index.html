Pick your printer first

  • DPIEach preset knows the resolution the printer wants, such as 300 for plotters and print shops.
  • Size capRoll width and size limits are checked. The plotter preset caps width at 36 in.
  • Paper previewSee the poster as glossy, luster, matte, bond, canvas or plain paper.
  • File limitSet a size limit in MB to match the upload form. The plotter preset uses 75 MB.

Example Checks (plotter on bond paper, 40 in wide, 150 DPI)

  • error
    40 in is wider than this printer's 36 in maximum
    Fix: Use 36 x 54 in
  • warn
    150 DPI is below the 300 DPI this printer wants
    Fix: Set quality to 300 DPI

RGB only on the web. This page makes RGB files, which most shops convert. CMYK output needs the command-line tool.
